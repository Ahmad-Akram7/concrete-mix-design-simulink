Architecture

Model Flow

The model follows the ACI 211.1 procedure as a sequential calculation chain.

📥 Inputs
Strength, Slump, Agg Size, FM
→
📊 ACI Lookup Tables
Water, w/c, CA Volume
→
🔢 Math Operations
Cement, CA Mass
→
📦 Subsystem
Absolute Volume → FA
→
📤 Outputs
Water, Cement, CA, FA
Governing Equation — Cement Content
C = W ÷ (w/c)

Where W = water content (kg/m³) and w/c = water-cement ratio from ACI Table 2

Block Type Library Purpose
Constant Sources All design input parameters
2-D Lookup Table Lookup Tables ACI Tables 1 & 3
1-D Lookup Table Lookup Tables ACI Table 2 (w/c ratio)
Divide / Product Math Operations Cement & mass calculations
Sum Math Operations Absolute volume summation
Subsystem Ports & Subsystems Encapsulates fine aggregate logic
Display Sinks Output: Water, Cement, CA, FA

Quick Start

Get Started in Minutes

Clone, open, and run — it's that simple.

1

Prerequisites

MATLAB R2020b or later with the Simulink base package installed.

2

Clone the Repo

Download or clone the repository to your local machine.

3

Open & Run

Open the .slx file in Simulink, set your inputs, and press Run.

# Clone the repository
git clone https://github.com/Ahmad-Akram7/concrete-mix-design-simulink.git

# Open MATLAB and navigate to the project folder
cd concrete-mix-design-simulink

% Open the model
open('Concrete_Mix_Design_Simulink_v9.slx')

% Set your inputs in the Constant blocks:
%   - Target_Strength_MPa  (e.g., 25, 35, 45)
%   - Slump_mm             (e.g., 50 or 100)
%   - Max_Agg_Size_mm      (10, 20, or 40)
%   - Fineness_Modulus      (2.40, 2.60, or 2.80)

% Hit Run (Ctrl+T) — results appear in the Display blocks instantly
